# Mini ATM Simulator using C

A beginner-friendly ATM Simulator developed using the C programming language as a First Semester Engineering project.

## Project Overview

The Mini ATM Simulator is a menu-driven console application that simulates basic ATM operations. It allows users to securely access their account using a PIN and perform basic banking transactions.

## Features

- PIN-based authentication
- Maximum 3 incorrect PIN attempts
- Check account balance
- Deposit money
- Withdraw money
- Change ATM PIN
- Input validation
- Menu-driven interface

## Technologies Used

- Programming Language: C
- Compiler: GCC (MinGW)
- IDE: Visual Studio Code

## Concepts Used

- Variables and Data Types
- Conditional Statements (if-else)
- Switch Case
- Loops (while and do-while)
- Functions
- Structures
- Pointers

## Default Login Credentials

- PIN: `1234`
- Initial Balance: `5000`

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Compile the program:

   ```bash
   gcc atm.c -o atm
   ```

4. Run the program:

   ```bash
   ./atm
   ```

   On Windows PowerShell:

   ```powershell
   .\atm.exe
   ```

## Project Purpose

This project was developed to understand and practically implement fundamental C programming concepts through a simple banking application.

## Disclaimer

This is an educational simulation project and is not connected to any real banking system.
